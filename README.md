# Asma Aljadani, portfolio

My personal website: who I am, what I build, and how to reach me. Built mobile first.

**Live:** https://asmaaljadani01.github.io/

## Features
- Spot the bug: a small game with five interface mistakes to find and fix
- Works without JavaScript for all main content

## Built with
HTML, CSS and JavaScript. No framework and no build step. Fonts from Google Fonts. Built with help from an AI assistant.

## Run it
Download the repository and open `index.html` in a browser.

## Files
| File | What it holds |
|---|---|
| `index.html` | All the text |
| `style.css` | Colours (top of the file) and layout |
| `script.js` | Spot the bug game and copy email button |
| `preview.png` | Link preview image, 1200 × 630 |
